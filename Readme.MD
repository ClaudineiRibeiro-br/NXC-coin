Overview

NOMATRIX Chain is a private Ethereum-compatible blockchain running Proof of Authority (PoA/Clique) consensus, purpose-built to power the NOMATRIX ONE platform — a location-based augmented reality PWA.

NXC is the native coin of the NOMATRIX Chain and also deployed as an ERC-20 token on the same chain, with a total fixed supply of 1,000,000,000 NXC.

Add to MetaMask

To connect MetaMask manually to NOMATRIX Chain:

Open MetaMask → Settings → Networks → Add Network
Fill in the fields:
Network Name:   NOMATRIX Chain
RPC URL:        http://75.119.142.94:8545
Chain ID:       19840
Currency Symbol: NXC
Block Explorer: (leave blank for now)
Click Save — done! ✅
Add NXC Token to MetaMask

After connecting to NOMATRIX Chain:

Go to Assets → Import tokens
Enter the contract address:
0xEd509C207E1F653b35f89cb8b8cd70aA6bf04ABE
Symbol NXC and 18 decimals will auto-fill.
Click Add custom token → Import tokens ✅
