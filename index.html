Connect your wallet

Add NOMATRIX Chain to MetaMask in one click, or follow the manual steps below.

Manual setup:

  1. Open MetaMask → Settings → Networks → Add Network
  2. Enter Network Name: NOMATRIX Chain
  3. Enter RPC URL: http://75.119.142.94:8545
  4. Enter Chain ID: 19840
  5. Enter Symbol: NXC
  6. Click Save — you're connected ✅

To import the NXC token:

  1. Go to Assets → Import tokens
  2. Paste contract: 0xEd509C207E1F653b35f89cb8b8cd70aA6bf04ABE
  3. Symbol and decimals fill automatically → Import tokens ✅
